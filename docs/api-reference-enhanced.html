📋 Order Management

Place Order O(log n)

placeOrder(self: *ShardedOrderbook, side: OrderSide, price: u64, amount: u64, order_id: u64) !void

Algorithm Breakdown

Orders are placed using a cache-optimized skip list data structure, providing O(log n) insertion time with excellent cache locality. The sharded architecture reduces contention by distributing orders across price-based partitions.

Operation Complexity Analysis

AbyssBook (Skip List)

O(log n)
Cache-friendly, SIMD optimized

Red-Black Tree

O(log n)
Poor cache locality

Linked List

O(n)

Cancel Order O(1)

cancelOrder(self: *ShardedOrderbook, order_id: u64) !bool

⚡ Performance Note

Order cancellation is O(1) due to direct hash map lookup of order IDs, combined with efficient skip list node removal using cached pointers.

Modify Order O(1)

modifyOrder(self: *ShardedOrderbook, order_id: u64, new_amount: u64) !bool
Amount-only modification O(1)
Price modification O(log n)

🎯 Advanced Order Types

TWAP Order O(t × k)

placeTWAPOrder(self: *ShardedOrderbook, params: TWAPParams) !void

TWAP Execution Strategy

Time-Weighted Average Price orders are executed across t time intervals, with each interval potentially matching k orders. The algorithm optimizes for minimal market impact while maintaining consistent execution pace.

pub const TWAPParams = struct { side: OrderSide, total_amount: u64, duration_seconds: u64, num_intervals: u64, max_participation: f64, // Maximum % of volume per interval };

📦 Bulk Operations

Bulk Insert Orders O(m × log n)

bulkInsertOrders(self: *ShardedOrderbook, orders: []const Order) !void

SIMD Optimization

Bulk operations leverage SIMD vectorization to process 8 orders simultaneously, effectively reducing the constant factor in the complexity equation. The actual performance approaches O(m × log n / 8) on AVX2-capable processors.

📊 Market Data

Get Best Bid/Ask O(1)

Constant Time Access

Best bid/ask prices are maintained as cached values and updated incrementally as orders are added/removed, providing instant O(1) access to top-of-book data.
